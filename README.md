# Jrew Creations

Static website for Jamaican patties, crochet fashion and community in Toronto.

## Deploy

Import this repository into Vercel. Choose the Other framework preset; leave the build command blank and use dist as the output directory. vercel.json supplies the output directory. No environment variables are required.

## Edit

Content: dist/index.html. Styling: dist/style.css. Menu filters: dist/script.js. Images: dist/assets/.

## Photography

Callaloo patty: Hue Pham / West End Phoenix. Crochet: Black Designers of Canada. Brunch and Craft & Yap artwork: Jrew Creations official Eventbrite listings linked from their Linktree. Confirm photo reuse with the owners before public launch.
